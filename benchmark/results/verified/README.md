# Verified benchmark records

This directory contains the only publishable benchmark evidence. Each Markdown record must come from one completed `qcpu_18i` Slurm job, include the same-job comparator result and both tools' wall-clock and peak-RSS values, and identify the node, threads, workload, and tool versions.

Do not add reconstructed values, records from separate jobs, or summaries derived from ignored raw CSV or job trees.
