# FlashFry Off-Target Scoring Oracle Harness

## Purpose

This directory contains the **oracle harness infrastructure** for validating
ProkaDiff's CFD (Doench 2016) and Hsu2013 scoring implementations against
FlashFry 1.15 golden output.

## Status

```
BLOCKED_EXTERNAL_DEPENDENCY
```

FlashFry 1.15 is **not available** in the current environment.
All scoring gates (CFD, Hsu2013) remain in `disabled` / `experimental` state
until real FlashFry output is collected and archived here.

## Directory Layout

```
benchmark/offtarget/flashfry/
├── README.md           — this file

├── scripts/

└── golden/
    ├── raw_flashfry.tsv        — (generated by run_flashfry.sh; do NOT hand-edit)
    └── normalized_flashfry.tsv — (generated by normalize_flashfry.py)
```

## Oracle Requirements

FlashFry 1.15 must be installed to populate `golden/`.

```
https://github.com/mckennalab/FlashFry/releases/tag/1.15
```

Key FlashFry output columns used:

| FlashFry column       | ProkaDiff field  | Notes                          |
|-----------------------|------------------|--------------------------------|
| `contig`              | `seq_id`         | exact match                    |
| `start`               | `start`          | coordinate convention TBD      |
| `stop`                | `end`            | coordinate convention TBD      |
| `target`              | `target_seq`     | 20-nt + PAM                    |
| `orientation`         | `strand`         | `FWD` → Plus, `RVS` → Minus   |
| `Doench2016CFDScore`  | `cfd_score`      | gate: must validate ≥ 100 pairs|
| `Hsu2013`             | `hsu_score`      | gate: must validate ≥ 100 pairs|

## Coordinate Convention Note

FlashFry coordinates are **0-based half-open** (`start` inclusive, `stop`
exclusive). ProkaDiff uses **1-based inclusive** (`start` to `end`).

Conversion (to be confirmed against a real run):
```
prokadiff_start = flashfry_start + 1
prokadiff_end   = flashfry_stop           # (stop is exclusive, so last nt is stop-1+1 = stop)
```

This convention will be confirmed and documented in
`docs/offtarget_coordinate_conventions.md` once real output is available.

## Release Gate

CFD and Hsu2013 scores remain `NA` in ProkaDiff output until:
- `golden/raw_flashfry.tsv` exists (≥ 100 scored pairs)
- `compare_scores.py` reports 0 failures within tolerance

See `scripts/compare_scores.py` for acceptance criteria.
