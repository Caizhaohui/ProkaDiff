# CRISPRitz 2.8.1 Bulge Oracle Harness

## Purpose

Validates ProkaDiff's bulge scanner (`crates/prokadiff-offtarget/src/rust_search/bulge.rs`)
against the CRISPRitz 2.8.1 reference implementation.

## Status

```
BLOCKED_EXTERNAL_DEPENDENCY
```

CRISPRitz 2.8.1 is **not available** in the current environment.
Bulge search flags (`--max-dna-bulge`, `--max-rna-bulge`) remain **EXPERIMENTAL**
until real CRISPRitz output is collected, normalized, and compared.

## Directory Layout

```
benchmark/offtarget/crispritz/
├── README.md               — this file
├── versions.tsv            — tool versions (CRISPRitz: NOT AVAILABLE)
├── cases.tsv               — bulge test case matrix
├── scripts/
│   ├── run_crispritz.sh         — invoke CRISPRitz 2.8.1 (exits BLOCKED if absent)
│   ├── normalize_crispritz.py   — convert raw output → normalized TSV
│   └── compare_bulges.py        — ProkaDiff vs CRISPRitz site-level parity
└── golden/
    ├── raw_crispritz.txt        — (generated by run_crispritz.sh; do NOT hand-edit)
    └── normalized_crispritz.tsv — (generated by normalize_crispritz.py)
```

## Release Gate

Bulge flags remain EXPERIMENTAL in ProkaDiff CLI until:
- `golden/raw_crispritz.txt` exists (real CRISPRitz 2.8.1 output)
- All core cases in `cases.tsv` pass `compare_bulges.py`
- precision = 1.000, recall = 1.000

Any discrepancy is documented in `benchmark/offtarget/BULGE_ISSUES.md`.
